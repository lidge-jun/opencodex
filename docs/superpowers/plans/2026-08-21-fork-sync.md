# Public Fork Sync Playbook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the approved public-fork workflow with the smallest diff: fork-owned docs, a Cursor sync skill, a no-op `src/fork` registration seam (Lab-style, composition-root only), then local git lanes (`archive/mixed-dev`, `vendor/dev`).

**Architecture:** Track `upstream/dev` on a fast-forward-only `vendor/dev` branch; keep a curated overlay on public `main`; rebuild disposable `run/dev` from vendor + selected `feat/*` + overlay. Fork runtime changes live under `src/fork/` and register through one synchronous call in `src/server/index.ts` after the Lab block—same boundary rule as Lab (router, lifecycle, responses/core never import fork). Agents analyze conflicts and run tests; humans land `main`.

**Tech Stack:** Bun-native TypeScript, `bun:test`, git lanes on `upstream` (`lidge-jun/opencodex`) and `origin` (`yansigit/opencodex`), Cursor skill for agent playbook.

## Global Constraints

- Authority: `docs/superpowers/specs/2026-08-21-fork-sync-design.md`
- Ponytail: shortest working diff; no new deps; no unused automation; no speculative merge bots, quilt, or global `git config`
- Never open this tree as an upstream PR; never force-push `main`; never reset `feat/*` worktrees
- `src/router.ts`, `src/server/lifecycle.ts`, `src/server/responses/core.ts` must not import `src/fork/`; only `src/server/index.ts` may call the seam, synchronously, after the Lab block (~L1805)
- No `src/fork` behavior beyond registration no-op in this pass; no CI workflow; no cherry-pick of the 65 mixed `dev` commits
- Integration branch to track: `dev` (not `upstream/main` unless cutting a release-shaped pin)
- Document `git config rerere.enabled true` for operators; agents must not run `git config`
- Local git lanes only in this pass: no push; no GitHub default-branch switch

## Branch lanes

| Branch | Role | Rewritten? | Public default? |
|---|---|---|---|
| `vendor/dev` | Exact fast-forward of `upstream/dev` | No (FF only) | No |
| `main` | Public daily driver: vendor + curated overlay | No | Yes |
| `overlay` | Optional linear local-forever stack; rebase allowed | Yes | No |
| `feat/…` | One change; upstream PRs cut from `vendor/dev` | Yes until landed | No |
| `run/dev` | Disposable: vendor + selected unmerged `feat/*` + overlay | Yes (rebuilt) | No |
| `sync/upstream-YYYYMMDD` | Throwaway merge branch; CI; then merge to `main` | Discarded after | No |
| `archive/mixed-dev-YYYYMMDD` | Snapshot of pre-split mixed `dev` | Frozen | No |
