## Activation and observable checks

1. Proxy admission bearer + valid Pool credential + no explicit Images provider: one intercepted Images call uses the stored Pool bearer; returned JSON stays in the Codex Images shape. The fake upstream's captured header set contains no proxy secret.
2. Same bearer + selected Pool account without usable credential + configured keyed provider: 401 from Pool and zero intercepted keyed calls. This observes the fail-closed paid-provider precedence.
3. Same bearer + Direct-only route: no caller-token forward; existing keyed/CCA or configuration error wins according to current selection.
4. An invalid or ambiguous assembled upstream Authorization: fixed-text 500 before any network send and probe lease released. A configured header with different casing cannot create a second credential on the wire. This is a synthetic negative security fixture, not a live credential test.
