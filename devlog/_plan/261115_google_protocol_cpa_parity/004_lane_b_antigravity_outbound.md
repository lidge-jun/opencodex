## Highest-value gaps (ranked)

1. X1 + X2: parse google.rpc.ErrorInfo.reason (QUOTA_EXHAUSTED, RATE_LIMIT_EXCEEDED, INSUFFICIENT_G1_CREDITS_BALANCE) and use RetryInfo.retryDelay / metadata.quotaResetDelay (full Go-duration syntax) for in-place backoff, cooldown and the client Retry-After. Today a body-only delay is invisible to the transient retry loop.
2. X3: recognise 403 TOS_VIOLATION (code 403, PERMISSION_DENIED, ErrorInfo reason TOS_VIOLATION) on HTTP and in-stream errors, and pause the account the way VALIDATION_REQUIRED / verify-account already do.
3. S7: validate Claude-on-CCA thinking signatures by format before forwarding, not only by presence.
4. R7: add toolUsePromptTokenCount to input tokens.
5. M1: nest tool-result images under functionResponse.parts for CCA (not only Vertex Argon).
6. TL3: confirm whether Claude VALIDATED rejects argument-less tool schemas; if so add CPA's required "reason" placeholder.
7. R4: treat a stream with no text/tool output (signature + usage only) as a failure.
8. E3/E4: requestType "image_gen" / "web_search" and their requestId/sessionId shapes for the image route and the search sidecar.
9. E11: optional GOOGLE_ONE_AI credits fallback (enabledCreditTypes) after quota exhaustion.
