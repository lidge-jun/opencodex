# A — CPA inbound Google surface + Interactions API vs opencodex

Scope: CPA inbound `/v1beta` (generateContent family, models, Interactions) compared with opencodex `dev` (d842c1352e) and PR #8742 (`pr/8742` = d21ed22ea8).
CPA paths are relative to `devlog/_chase/_cca` (HEAD e96d4c4, 2026-11-15). opencodex paths are relative to the repo root; `#8742:` means read with `git show pr/8742:<path>`.
Method: read-only source inspection with rg/sed. Nothing was executed, so runtime behaviour is inferred from source. Rows marked *(inferred)* are my reading of the code and have not been exercised.

Baseline: **opencodex dev has no inbound Gemini or Interactions surface at all.** `rg -i 'v1beta|interactions' src` only hits upstream discovery/adapter code (src/adapters/google.ts:1309-1312, src/oauth/index.ts:1240-1244). `rg -i '/interactions|previous_interaction|interaction\.created' src gui/src docs-site/src` finds nothing. All "have" rows below exist only because of #8742.

## Highest-value gaps (ranked)

1. **R23, thoughtSignature round-trip in #8742 (P1).** The codec discards `thoughtSignature` on inbound `functionCall`/text parts and never emits it outbound (#8742:src/protocols/codecs/gemini.ts:197-264,331-356). A Gemini-3 upstream returns 400 on the second tool turn unless the Chat path's server-side store (src/responses/thought-signature-replay.ts) happens to rescue it. Smallest fix: map `part.thoughtSignature` to `tool_calls[].extra_content.google.thought_signature`, and back out on response and stream chunks. The wire shape already exists (src/responses/provider-opaque-metadata.ts:17,57-60).
2. **I01–I13, no `/v1beta/interactions` (P2).** Build one Interactions→Chat codec beside `src/protocols/codecs/gemini.ts` and reuse the #8742 bridge (`native-chat-bridge.ts`) and error body. Copy the CPA event vocabulary (I10) and the completion gating (I12). Return 400 for `agent`, `background:true`, and `previous_interaction_id` unless they can be honored (I02, I14, I16).
3. **R24, silently dropped hosted tools (P2).** `googleSearch`, `urlContext`, and `codeExecution` vanish (#8742:src/protocols/codecs/gemini.ts:62-63), which violates the codec's own rule against silently changing an answer. Return 400, or pass the tools through when the selected route is a Google adapter.
4. **R07, `countTokens` returns 501 (P2).** CPA serves it for every provider. Answer `{"totalTokens":N}` from opencodex's estimator, or from the provider's endpoint when one exists.
5. **R22, `fileData` and non-image `inlineData` return 400 (P2).** PDFs, audio, and Files-API URIs are common genai-SDK inputs. CPA forwards them.
6. **R11, model metadata (P2).** Add `inputTokenLimit`, `outputTokenLimit`, and `description` from the catalog so Gemini clients can budget context.
7. **R05/R06 (P3).** Add the `$alt` alias and an optional SSE `: keep-alive` comment before the first token.
8. **R17 nit (P3).** Fill in `STATUS_NAMES` for 402, 408, 409, 422, 500, and 502.
