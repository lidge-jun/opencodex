## 루프 아키타입

**spec-satisfaction.** 검증자가 done을 정의한다: "열린 이슈 23 + 열린 PR 14
전부가 최소 한 묶음에 배정되었고, 각 항목마다 결정 지점이 명시되었는가"는
기계적으로 확인 가능하다. open-ended 최적화가 아니다.

- 이슈 23건 → A(0) B(2: #425,#294) C(6) D(3) E(2) F(0) + 이미 결정됨(#540)
  + IN-FLIGHT PR 담당(#476, #42, #418) + roadmap 대기(#95, #386, #414, #415, #509, #521)
- PR 14건 → A(3) B(4) F(4: #491,#429,#526,#527) + 개별(#533, #447, #461)
