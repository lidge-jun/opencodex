# 008 — OpenCodex 기준 기능 인벤토리

분석 기준은 `origin/dev` `9e0e298ef9720cfeaa1209f090a68e4d1965d2a1` (2026-11-21 KST)의 `.tmp/chase/opencodex-dev/` export다. `ocx:` 경로와 줄은 모두 이 export에 상대적이다. `structure/INDEX.md:43–135`에서 데이터 경로와 어댑터를, `:137–183`에서 클라이언트·운영 경로를 찾고 실제 등록부·핸들러·설정 해석으로 확인했다.

## 요약

- Codex는 Responses HTTP/SSE와 opt-in WebSocket을 같은 라우팅 파이프라인으로 사용한다. 네이티브 응답·compact와 어댑터 변환·휴대 가능한 이력 경로가 있다.
- Claude Code는 Messages와 `count_tokens`를 사용한다. 일반 변환, 자격 증명과 요청 조건을 충족하는 native Messages, Antigravity 전용 직접 인코딩이 각각 등록돼 있다.
- Chat Completions, Gemini generateContent/Interactions, Ollama 호환 ingress가 같은 모델·키 정책을 사용한다. Gemini embedding 동작은 등록된 메서드에서 501을 반환한다.
- Codex·Anthropic·일반 OAuth·공급자 API 키 풀은 교체 범위와 승인 조건이 다르다. 캐시 친화성, 쿼터 냉각, 콤보 재시도는 각각 선택·전송 경계에 반영된다.
- Codex 및 Claude 설정 외에도 24개 선언형 config export, 별도 native/gateway 연결, Remote Link의 설정 소유권과 복구가 있다.
- 공유 설치는 이름 있는 데이터 키, 모델 범위, 키별 사용량, 관리자 인증, Hub·Child 연결을 제공한다. 조직별 청구·사용자 관리는 비교 검증 대기다.
- 로컬 플러그인은 공급자 전송 훅을 등록한다. Compatibility Lab은 요청 처리에서 분리된 활성화 게이트와 fixture·live 증거 경로를 갖는다.
- Windows/macOS/Linux 서비스와 Docker 배포, Desktop 트레이·업데이트 경로가 있다. 열린 계획의 이행 상태는 기준 소스로 개별 확인했다.
