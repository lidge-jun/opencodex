# 004 — 초등학생도 이해할 수 있는 설명

## 이 문서는 뭐예요?

OpenCodex는 여러 AI 선생님(모델)에게 숙제를 대신 전달해 주는 **우체국** 같아요.  
지금 우체국 민원함(이슈)과 고치는 중 상자(PR)를 열어서, **진짜 고장**만 골라 급한 순서표를 만들었어요.

오늘은 코드를 고치지 않았어요.  
고장 목록을 정리하고, 먼저 고칠 것만 줄을 세운 날입니다.

## 숫자로 보면

- 열려 있는 이야기(이슈): **70개**
- 그중 라벨이 "bug"인 것: **23개**
- 진짜 고장/고장 비슷으로 본 것: 대략 **24개 안팎**
- 고치는 중인 상자(버그 PR): **10개**
- 기능 추가 부탁은 버그 줄에서 **뺐어요**

## 아주 쉽게 말하는 우선순위

### 0등 줄 — 제일 먼저 (중국 Kimi/Moonshot)

**Zhaorui 님 제보**

1. Moonshot 기본 설정은 주소가 항상 `.ai`라서, 중국(`.cn`) 키를 쓰려면 커스텀으로 직접 넣어야 했어요.  
2. 잔액 **숫자는 맞는데 단위가 달러($)로 보여요.** 중국 플랫폼 잔액은 **위안(¥/CNY)** 이어야 해요.

그래서 우선순위를 맨 위로 올렸고, 고치는 방향은:

- Moonshot에 **국제(.ai) / 중국(.cn) / 직접 입력** 선택지를 준다  
- 잔액 표시는 호스트 기준: `.cn` → **¥ CNY**, `.ai` → **$ USD**  
  (위안을 달러로 바꾸지 않음. 단위만 맞게 붙임)

## 왜 이 순서인가요?

먼저 **이미 고친 상자**를 넣으면, 민원함이 빨리 비어요.  
그다음 **우체국 문/신분증/윈도우 경로**처럼 시작조차 못 하는 고장을 고칩니다.  
그다음에 **한 선생님(모델)만 아픈 것**, 마지막에 **시험 기계/숫자 보기**를 봅니다.

쉬운 비유:

1. 이미 고쳐 둔 장난감을 상자에 넣기  
2. 교실 문 잠긴 것 열기  
3. 연필이 부러진 자리 고치기  
4. 성적표 글씨 예쁘게 만들기

## 오늘 한 일과 안 한 일

### 한 일
- 민원함/상자 전부 새로 셈
- 진짜 고장 / 가짜 고장 / 기능 부탁 나누기
- 급한 순서표 만들기
- 이 설명을 문서에 저장하기

### 안 한 일
- 코드 고치기
- PR 합치기
- 이슈에 댓글 달기 / 닫기
- 인터넷에 올리기(push)
