# 011 — 지금 남은 것들 (초등학생도 알아볼 수 있게)

아침에 쓴 `004` 문서는 "고치기 전" 이야기예요.
이 문서는 **저녁에 실제로 고치고 난 뒤** 남은 것만 다시 씁니다.

## 먼저, 오늘 한 일

OpenCodex는 여러 AI에게 일을 대신 전달해 주는 **우체국**이에요.
오늘은 고쳐 놓은 상자(PR) 14개를 우체국에 실제로 넣었고, 민원 6개를 닫았어요.

제일 급했던 것부터:

- **중국 Kimi 문제** — 주소를 항상 `.ai`로만 보내서 중국(`.cn`) 열쇠를 쓰는 사람은 매번 직접 주소를 적어야 했어요. 이제 국제/중국/직접입력 중에 고를 수 있어요.
  잔액도 고쳤어요. **숫자는 원래 맞았는데 단위가 틀렸어요.** 중국 잔액은 위안(¥)인데 달러($)라고 써 있었거든요. 이제 주소에 맞춰 단위를 붙입니다. 돈을 바꾸는 게 아니라, 이름표만 바르게 붙인 거예요.
- **맥에서 우체국이 계속 죽던 문제(#1599)** — 문 앞에서 넘어져서 아예 문을 못 열었어요. 이제 예전 설정을 안전한 곳에 **복사해서 보관한 다음** 계속 진행해요. 버리지 않고요.
- 그 외에 도구 이름 잘못 부르기, Volcengine 400 오류, Grok의 "아주 깊게 생각하기" 막힘, Cursor 도구 줄 꼬임 등 열 몇 가지.

## 고치다가 발견한 재미있는 일

상자를 하나씩 열어보면 다 멀쩡했는데, **두 개를 같이 넣으니까** 시험이 틀렸어요. 두 번이나요.

누구의 잘못도 아니에요. 각자 만들 때는 옆 상자가 아직 없었으니까요.
예를 들어 한 상자가 숫자 칸을 11개에서 12개로 늘렸는데, 다른 곳의 시험지에는 "11개여야 함"이라고 적혀 있었어요. 그래서 시험지를 12개로 고쳤습니다.

이래서 합칠 때마다 전체 시험을 다시 봐야 해요. 오늘도 매번 11,500개쯤 되는 시험을 처음부터 다시 돌렸어요.

## 지금 남은 고장 20개

### 아직 사람이 많이 불편한 것 (제일 먼저)

1. **#1589, #1573 — 윈도우 이름표와 한글 경로**
   컴퓨터가 "너 누구야?"를 확인하려는데, 창을 숨긴 채로 물어보면 대답을 못 해요.
   그리고 폴더 이름에 한글이 있으면 글자가 깨져서(`�`) 자기 가방을 못 찾아요.
   한국에서 윈도우를 쓰는 사람에게 특히 중요해요.

2. **#1527 — Cursor로 긴 이야기를 보내면 막힘**
   같은 계정으로 Cursor에 직접 보내면 잘 되는데, 우리 우체국을 거치면 아파요.
   그러면 원인은 우체국 쪽에 있을 가능성이 커요.

3. **#1582 — 주소를 두 번 붙이는 문제**
   사용자가 주소를 통째로 붙여넣으면 `/chat/completions/chat/completions`처럼 되어서 "그런 곳 없어요(404)"가 나요.

4. **#1562 — 화면에서 아무 말 없이 실패**
   `codex` 프로그램이 없을 때 조용히 안 켜져요. 안 되면 안 된다고 말해 줘야 해요.

5. **#1302 — 시험 기계가 가끔 멈춤**
   손님 문제는 아니고 개발자 쪽 문제예요. 그런데 이게 느려지면 다른 고치는 일도 다 느려져요.
