# 020 — work-phase 2: jawcode 가격 번들 생성기와 Go 패키지

근거: `001` G1. 측정된 규모는 `003` W2 — 측정 요청 89,479건 중 51,708건(57.8%)이 unpriced.

## 문제

Go에 jawcode 모델 메타데이터 번들이 없다(`find go -name '*jawcode*'` → 출력 없음).
TS는 15개 프로바이더 번들에 724행, 그중 652행이 0이 아닌 가격을 갖는다.

## 설계 결정: 무엇을 소스로 삼는가

두 선택지가 있었다.

| 안 | 소스 | 문제 |
| --- | --- | --- |
| A | 외부 `../jawcode/packages/ai/src/models.json` (1.8MB) | 저장소 밖 체크아웃 의존. CI에 없다. TS 생성 시점과 Go 생성 시점이 갈리면 두 런타임이 **다른 가격**을 갖는다 |

## 생성기 계약 (A 감사 반영)

모델 행은 **임포트**해서 얻는다. `bun`으로 TS 모듈을 로드하면
`listJawcodeModelMetadata`가 `rowToMetadata`의 null 처리와 `compactRow` 꼬리 절단을
이미 적용한 값을 준다. 정규식으로 행을 긁으면 그 규칙을 재구현해야 하고, 그 재구현이
곧 드리프트 지점이 된다.

**그런데 두 가지는 export되지 않는다.** 실측:

```
$ bun -e 'const m = await import("./src/generated/jawcode-model-metadata.ts"); console.log(Object.keys(m).join(", "))'
findJawcodeCostByModelId, getJawcodeModelMetadata,
getJawcodeModelMetadataCaseInsensitive, listJawcodeModelMetadata, resolveJawcodeProvider
```

`PROVIDER_ALIASES`(`src/generated/jawcode-model-metadata.ts:15`)와
`COST_VENDOR_PRIORITY`(`:79`)는 모듈 내부 const다. `resolveJawcodeProvider`는
**주어진 키를 조회**할 뿐 키 목록을 열거해주지 않으므로, 임포트만으로는 별칭 맵 전체와
벤더 우선순위 순서를 복원할 수 없다. 각각 다르게 해결한다.

### 별칭: 상류 소스에서 파생한다 (스크레이핑 아님)

별칭은 생성물이 원본이 아니다. 기존 생성기가 상류에서 만든다:

```ts
// scripts/generate-jawcode-metadata.ts:3,5
import { deriveJawcodeAliases } from "../src/providers/derive";
const PROVIDER_ALIASES = deriveJawcodeAliases();
```

`deriveJawcodeAliases`는 **export되어 있다**(`src/providers/derive.ts:267`).
Go 생성기도 같은 함수를 부르면 된다. 동등성 실측:

```
derived keys: 18 | committed keys: 18
same key SET: true
value mismatches: none
ordering differs only: true
```

키 집합과 값이 정확히 같고 삽입 순서만 다르다. Go `map`은 순서가 의미 없으므로 무해하다.
이 방식은 정규식 파싱보다 낫다: TS 생성기와 **같은 함수**를 쓰므로 정의상 드리프트가 없다.

**가드**: 생성기는 `deriveJawcodeAliases()`의 결과와, 커밋된 생성물에서 읽은 별칭 맵을
대조해 불일치 시 throw한다. 두 소스가 갈라지면 즉시 실패해야 한다.

### 벤더 우선순위: 생성물에서 파싱하되 검증한다

`COST_VENDOR_PRIORITY`는 `scripts/generate-jawcode-metadata.ts:39-43`의
`COST_VENDOR_BUNDLES`에서 오지만 그 배열은 스크립트 지역 변수라 임포트할 수 없다.
따라서 커밋된 생성물의 한 줄을 파싱한다(`:79`):

```ts
const line = src.match(/^const COST_VENDOR_PRIORITY = (\[.*\]);$/m);
if (!line) throw new Error("COST_VENDOR_PRIORITY not found — generated format changed");
const priority: string[] = JSON.parse(line[1]);
if (priority.length === 0) throw new Error("empty vendor priority");
```

**순서가 계약이다.** `findJawcodeCostByModelId`(`:80-90`)는 이 배열을 순서대로 돌며
0이 아닌 첫 가격을 반환한다. 순서가 틀리면 중복 모델 ID에서 다른 벤더가 이긴다.
그래서 Go 측 테스트가 배열을 **순서까지** 고정한다.

### 프로바이더 이름: 정규식을 느슨하게

초안 정규식 `/^  "([a-z0-9-]+)": \[/gm`은 현재 15개 번들을 모두 잡지만, 점·밑줄·대문자가
들어간 키가 생기면 **조용히 누락**한다. 누락은 가격 소실로 이어지므로 넓게 잡는다:

```ts
const providers = [...src.matchAll(/^  "([^"]+)": \[/gm)].map(m => m[1]);
if (providers.length === 0) throw new Error("provider scan matched nothing");
```

0개면 즉시 throw한다. 조용히 빈 번들을 생성하는 것이 최악의 실패 모드다 —
빌드는 통과하고 가격만 전부 사라진다.

### 부동소수: 최단 왕복 표기

JS `String(v)`가 최단 왕복 표기를 낸다. 실측:

```
0.09999999999999999 -> "0.09999999999999999"
0.024999999999999998 -> "0.024999999999999998"
1e-7 -> "1e-7"   (Go float64 리터럴로도 유효)
```

Go의 `strconv.ParseFloat`는 이 문자열들을 JS와 **같은 비트 패턴**으로 파싱한다.
반올림해서 `0.1`이나 `0.025`로 적으면 1 ULP가 달라진다. 절대 반올림하지 않는다.

## 생성되는 Go 형태

`init()`으로 조립하지 않는다. 리터럴 맵이면 컴파일 타임에 확정되고 시작 비용이 없다.

```go
// Code generated by scripts/generate-jawcode-go.ts. DO NOT EDIT.
// Source: src/generated/jawcode-model-metadata.ts (the same bytes the
// TypeScript runtime reads), so Go and TS cannot drift apart.
package jawcode

type Cost struct {
	Input      float64 `json:"input"`
	Output     float64 `json:"output"`
	CacheRead  float64 `json:"cacheRead"`
	CacheWrite float64 `json:"cacheWrite"`
}

type Model struct {
	Provider      string
	ID            string
	ContextWindow int
	MaxTokens     int
	Reasoning     bool
	WireModelID   string
	Cost          *Cost // nil when the source row carried no cost tuple
}

var providerAliases = map[string]string{
	"anthropic": "anthropic", "anthropic-apikey": "anthropic", /* ... */
}

// models[provider][modelID]
var models = map[string]map[string]Model{
	"anthropic": {
		"claude-opus-4-6": {Provider: "anthropic", ID: "claude-opus-4-6",
			ContextWindow: 1000000, MaxTokens: 128000, Reasoning: true,
			Cost: &Cost{Input: 5, Output: 25, CacheRead: 0.5, CacheWrite: 6.25}},
	},
}

var costVendorPriority = []string{"anthropic", "openai", "google" /* ... */}
```

`Cost`가 포인터인 이유(A 감사로 근거 정정): TS `rowToMetadata`가 네 값이 모두 non-null일
때만 `cost`를 채우므로 메타데이터 API 자체가 optional이다. 포인터는 그 계약을 보존한다.

초안은 "0행과 없음을 구분해야 가격 해석이 달라진다"고 썼는데 **그건 부정확하다** —
`src/usage/cost.ts`는 없음과 전부-0을 **둘 다** 오버레이/폴백으로 흘려보낸다.
다만 실측상 현재 카탈로그는 `noCost: 0, allZero: 72, nonZero: 652`이므로,
0행 72개는 실재하고 이들이 오버레이 후보로 남아야 한다는 점은 그대로 유효하다.

## 조회 함수 (TS 대응)

| Go | TS 대응 | TS 위치 |
| --- | --- | --- |
| `ResolveProvider(provider string) (string, bool)` | `resolveJawcodeProvider` | `jawcode-model-metadata.ts:55-57` |
| `Metadata(provider, modelID string) (Model, bool)` | `getJawcodeModelMetadata` | `:59-63` |
| `MetadataCaseInsensitive(provider, modelID string) (Model, bool)` | `getJawcodeModelMetadataCaseInsensitive` | `:65-70` |
| `List(provider string) []Model` | `listJawcodeModelMetadata` | `:72-74` |
| `FindCostByModelID(modelID string) (string, Cost, bool)` | `findJawcodeCostByModelId` | `:80-90` |

`FindCostByModelID`는 `costVendorPriority`를 순회하며 **0이 아닌 첫 가격**만 반환한다.
TS와 같은 조건(`input!==0 || output!==0 || cacheRead!==0 || cacheWrite!==0`).
맵 순회는 순서가 비결정적이므로 반드시 슬라이스를 순회해야 한다 — 여기서 맵을 쓰면
같은 입력에 다른 벤더가 나오는 비결정 버그가 된다.

`List`는 모델 ID 사전순 슬라이스를 반환한다(맵 순회 비결정성 차단).

## 활성화 시나리오 (C-ACTIVATION-GROUNDING-01)

이 사이클은 데이터만 넣고 해석 체인 배선은 `030`이다. 활성화 증거는 **데이터 정합성**이다.

트리거: 생성된 Go 번들을 TS와 같은 질의로 두드린다.
관찰: 아래 단언이 실제 숫자로 통과.

1. 프로바이더 번들 15, 전체 행 724, 0 아닌 가격 행 652.
   (`003`의 bun 명령이 낸 값. 생성기가 조용히 일부를 흘리면 여기서 걸린다.)
2. 표본 행 정확 일치: `openai`/`gpt-5.6-sol` → `{5, 30, 0.5, 6.25}`,
   `anthropic`/`claude-opus-4-6` → `{5, 25, 0.5, 6.25}`.
3. `FindCostByModelID("claude-opus-4-6")` → `anthropic`
   (벤더 우선순위 첫 히트 = 순회가 결정적인지).

발화 증명: 행 수 단언은 생성기 회귀(정규식 0매치, 꼬리 절단 오류)를 직접 잡는다.
번들이 비면 652 ≠ 0으로 실패한다.

## 위험

- **생성물 크기.** 724행이면 Go 소스 수백 KB다. 컴파일 시간을 측정하고 30초 이상
  늘면 `go:embed` + JSON으로 전환한다(그 경우 시작 시 파싱 비용이 생기므로 기본은 리터럴).
- **재생성 체이닝.** `src/generated/`가 갱신되면 Go도 갱신돼야 한다. `package.json`의
  기존 jawcode 생성 스크립트 뒤에 Go 생성기를 체이닝한다.
- **부동소수 표기.** TS의 `0.09999999999999999` 같은 값을 반올림하면 안 된다.
  생성기는 최단 왕복 표기로 출력한다.
