## 1. VERDICT

**yes** — on current `dev` (`cd813d3d9`) there is still no per-model free filter. Live `/models` rows can still carry a `pricing` object, but `catalogHintsFromModelsApiItem` drops it, `CatalogModel` / `GET /api/models` expose no model-level price or `pricingStatus`, and both Dashboard lists only substring-search. Existing “free” UI is **provider-tier** (`freeTier` / `keyOptional`), which is why OpenRouter (`freeTier` unset/false, mixed paid + `:free` slugs) cannot be filtered to $0 models. No PR currently targets #3666.

## 3. MINIMAL FIX SHAPE

One shared classifier, then two consumers.

1. **`catalogHintsFromModelsApiItem`** (or a helper it calls): map `pricing.prompt`/`input` + `pricing.completion`/`output` (numeric or numeric string) → `pricingStatus: "free" \| "paid" \| "unknown"`. Put the field on `CatalogModel`.
2. **`listManagementModelRows`**: field already spreads via `...m`; keep `manualPricing` orthogonal.
3. **GUI toggle** in `renderGroup` ([gui/src/pages/Models.tsx](/Users/jun/.codex/worktrees/ae6a/opencodex/gui/src/pages/Models.tsx:1411)) and `ProviderModelInventory` ([gui/src/components/provider-workspace/ProviderModels.tsx](/Users/jun/.codex/worktrees/ae6a/opencodex/gui/src/components/provider-workspace/ProviderModels.tsx:77)): filter `pricingStatus === "free"` **before** search sort / `PAGE` / `CHIP_RENDER_CAP`; counts and empty states use the filtered set. Optional Free chip next to the Price button.
4. **`live()`** in [src/cli/models-runtime.ts](/Users/jun/.codex/worktrees/ae6a/opencodex/src/cli/models-runtime.ts:57): `--free-only` using the same field. Command is `ocx models live --provider openrouter --free-only`.

**POLICY (not mechanical):**

- Missing/partial/invalid/negative → `unknown`, **excluded** from free-only (maintainer + #3667 $0.00-usage trap).
- Do **not** treat `:free` suffix as free when pricing is absent (OpenRouter-only; Kilo/Nous differ).
- Auxiliary Kilo fields (`isFree`, request/image): v1 = prompt+completion both explicitly 0 only, or also fail closed on any non-zero auxiliary? Needs a call.
- Filter is session UX, not config (unless someone asks to persist).
- Do not reuse `modelCosts` zeros as “discovered free”.
- Do not fold this into #3667 (closed) or #3569 (Codex picker order).

## 6. RISKS / UNKNOWNS

- Kilo live `/api/gateway/models` shape (`isFree` vs zero prompt/completion vs extra fees) is **not** in this tree; contributor claim is unverified. Registry id is `kilo`, not “KiloCode”.
- OpenRouter prices are USD **per token** strings; overlays/jawcode are **per 1M**. Classifier must use numeric zero, not unit conversion.

- 200+ OpenRouter rows: filter must run before `PAGE=60` / `CHIP_RENDER_CAP=300` or free models stay hidden behind Show more.
- Initial-selection pending still lists every discovered id ([gui/src/pages/Models.tsx](/Users/jun/.codex/worktrees/ae6a/opencodex/gui/src/pages/Models.tsx:1424)); free-only is how you avoid enabling paid during that window.
