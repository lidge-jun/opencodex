## 왜 이 유닛이 존재하는가

사용자가 대시보드 모델 페이지에서 세 가지를 요청했다.

1. openai 네이티브 그룹 헤더에 프리셋 버튼. 누르면 드롭다운이 열리고
   272k / 372k / 1.05M 중에서 고른다. 1.05M은 실제로 되는 모델만 켜진다.
2. openai 그룹에만 없는 "컨텍스트 윈도우" 버튼을 추가. ("openai쪽에 왜 없는거야")
3. openai 그룹에 "커스텀 모델 추가"(+) 버튼 추가.

전제는 "OpenAI 모델이 1.05M을 지원한다"는 사용자 확인 사실이다. 이 유닛은 그 전제를
믿고 코드를 고치는 대신, **실제 계정으로 upstream에 요청을 쏴서 상한을 측정**한 뒤
측정값을 계약으로 삼는다.

## 범위

IN

- 네이티브 gpt-5.6-sol / terra / luna 광고 컨텍스트 계약 갱신 (측정 기반).
- 모델 페이지: 네이티브 그룹 컨텍스트 윈도우 버튼, 커스텀 모델 추가 버튼.
- 모델 페이지: 컨텍스트 프리셋 드롭다운 (272k / 372k / 1.05M).
- 서버: canonical `openai` provider의 컨텍스트 overlay 저장 허용 및 네이티브 소비 경로 연결.

OUT

- openai-apikey / openrouter 등 기존 1,050,000 계약 변경.
- gpt-5.5(272k), gpt-5.4(1M), gpt-5.3-codex-spark(100k) 컨텍스트 변경.
- src/lab/ 코어 경계, UI 리디자인.
