# 012 — 후속: Codex가 998k를 보여주는 문제 (context_window는 표시가 아니라 예산)

## 증상

사용자가 배포된 v2.23.0으로 Codex를 열었더니 컨텍스트 표시가 `27k / 998k tokens used`였다.
우리가 광고한 값은 1,050,000인데 998k가 나온다.

## 원인

Codex는 `context_window`를 **입력 예산**으로 쓴다. 표시값 998k는
`1,050,000 - 52,000`이며, 52k는 시스템 프롬프트 + 툴 정의 베이스라인이다.

즉 사용자가 998k까지 채우도록 유도되는데, 실측 상한은 922k다. 76k 초과다.
세션 후반에 `context_length_exceeded`를 맞는 구조이며, 이는 010에서
auto-compaction을 945,000이 아니라 922,000으로 클램프한 것과 **같은 이유**의 문제다.
그때는 compaction만 고쳤고, 광고 창 자체는 그대로 뒀다.

기존 네이티브 행들의 비율을 보면 Codex 계약이 분명하다:

| slug | context_window | auto_compact | 비율 |
| --- | --- | --- | --- |
| gpt-5.4 | 1,000,000 | 900,000 | 0.90 |
| gpt-5.5 | 272,000 | 244,800 | 0.90 |
| gpt-5.3-codex-spark | 100,000 | 90,000 | 0.90 |
| gpt-5.6-sol (배포됨) | 1,050,000 | 922,000 | 0.878 |

5.6만 비율이 어긋나 있다. 창을 실제 상한보다 크게 잡고 compaction으로만 막으려 했기 때문이다.

## 재측정 (2026-08-17, 배포 후 재확인)

| 목표 입력 | 결과 |
| --- | --- |
| 915,000 | 성공 (input_tokens 915,160) |
| 921,000 | 성공 (input_tokens 921,160) |
| 923,000 | `context_length_exceeded` |

922,000 경계는 그대로다.

## 선택지

| 안 | context_window | Codex 표시 | 평가 |
| --- | --- | --- | --- |
| A 현행 | 1,050,000 | ~998k | 실측 상한 76k 초과. 후반 실패 |
| B 실측 상한 | 922,000 | ~870k | 실제로 되는 최대치. 초과 없음 |
| C 라이브 값 | 872,000 | ~820k | 안전하지만 실측 대비 50k 손해 |

**B를 택한다.** 광고 창이 곧 입력 예산이므로, 그 값은 "실제로 넣을 수 있는 최대"여야 한다.
C는 upstream이 보고하는 `max_context_window`에 충실하지만, 그 값 자체가 측정과 어긋난다
(872k보다 큰 921k 입력이 실제로 통과한다). A는 사용자를 초과로 몰고 간다.

## 계약 변경

```
NATIVE_GPT56_CONTEXT_WINDOW  1_050_000 -> 922_000
NATIVE_GPT56_MAX_INPUT_TOKENS         922_000 (유지)
auto_compact_token_limit     922_000 -> min(floor(922000*0.9), 922000) = 829_800
```

auto-compact가 90% 규칙으로 돌아온다. 다른 네이티브 행과 같은 모양이 되고,
010에서 넣은 `min(90%, maxInput)` 클램프는 그대로 유지된다 — 이제 90%가 더 작아서
클램프가 발화하지 않을 뿐, 규칙이 사라지는 것은 아니다.

## 부수 영향

`[1m]` 마커가 사라진다. Claude/Desktop 경로는 `>= 1,000,000`을 1M 계약으로 읽는데
922,000은 그 아래다. 010에서 "GPT-5.6이 처음으로 authoritative 1M 모델이 된다"고 한
변화가 되돌아간다. 이것은 회귀가 아니라 **정정**이다 — 실제로 1M을 넣을 수 없는 모델에
1M 마커를 다는 것이 #854가 막으려던 바로 그 상황이다.

따라서 010/020이 갱신한 테스트 중 1M 승격을 전제한 것들을 되돌린다.

## 범위

- `src/codex/catalog/metadata.ts` 상수 1개.
- 1,050,000 / 922,000 기대값을 가진 테스트 갱신.
- `[1m]` 관련 픽스처를 010 이전 형태로 복귀 (gpt-5.6-sol이 sub-1M 픽스처로 돌아감).
- docs-site 및 structure SoT의 1,050,000 표기 수정.
- API 키 경로(`openai-apikey`, OpenRouter)의 1,050,000은 **건드리지 않는다** — 그쪽은
  별도 계약이고 이번 측정 대상이 아니다.
