# ADR-7456 — Mandatory translated Chat tool results

- Contract owner: [providers/chat-required-tool-results.md](../providers/chat-required-tool-results.md)
- Intent: Stop reporting a successful turn when an upstream Chat model ignores the caller's mandatory client-tool selection (#7456).
- Prior constraints: Forwarding `tool_choice` does not establish that a call occurred. A streamed answer may already be committed when the clean terminal arrives. Existing adapter parsers restore tool identities and own argument validation and byte accounting.
- Alternatives: Model/provider allowlists, replaying the same turn with a prompt nudge, rerouting a committed stream, or buffering every response until completion. These require separate capability evidence or violate the existing output/commit and memory boundaries.
- Choice: Reuse the shared mandatory-choice predicate in a small adapter decorator. Observe complete calls without retaining output. Leave selected-name authorization and namespace/code-mode alias restoration with the existing response bridge; an independent adapter name matcher would incorrectly reject legitimate echoes. Replace only a clean unmet terminal with a typed non-retryable error, retaining usage. Transfer the buffered terminal's existing retention lease to its replacement.
- Why: The actual result establishes the contract without inventing vendor capability or asking the upstream to execute twice. Direct and combo routes receive the same adapter verdict; their existing response owner keeps transport and commit decisions.
- Consequences: Already delivered text remains visible in a failed response. Admitted buffered Responses can retain HTTP 200 while their envelope has `status: failed`; streaming ends with `response.failed`. This patch does not preflight or reroute runTurn adapters, validate native passthrough, promise automatic recovery, or define a global capability registry. Sidecar-bearing catalogs remain with their existing execution owner, while client function, custom and tool-search calls use the restored adapter identity.
