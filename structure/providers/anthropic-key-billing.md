# Anthropic API-key billing recovery

`src/providers/anthropic-billing-refusal.ts` accepts only a complete error envelope on HTTP 400 or 402, an allowlisted error type/code, and the whole credit-balance refusal message. Its shared bounded-body reader inspects a clone with fatal UTF-8 decoding, an 8 KiB byte limit and a 250 ms deadline combined with client cancellation; inspection leaves the original terminal body readable. Truncated, malformed, oversized, stalled, unrelated and unreadable errors grant no recovery authority.

`src/providers/anthropic-billing-ownership.ts` captures the actual outgoing `x-api-key`, selected provider, resolved key, target and selection reference/revision synchronously at the physical fetch, after connection-policy/plugin header rewrites. A private response WeakMap retains that frozen binding; the owned response-body wrapper in `src/providers/request-pacing.ts` carries registered provenance without creating a marker on unmarked responses. Recovery compares this immutable send against the attempted route and current selection, never against rebuilt headers. The wrapper inherits egress transparency only from an already transparent executor. Changes to the current adapter, billing eligibility or configured headers revoke the prior response's authority. Missing/conflicting ownership, credential overrides and selection drift preserve the refusal without cooling or selecting another key.

`src/providers/anthropic-billing-recovery.ts` and `src/providers/key-failover.ts` reuse the ten-minute key-401 cooldown and recovery attribution for Anthropic key pools with at least two entries. Native Messages and translated Responses recover only before output, within their shared physical-send/hop allowance; translated Responses counts eligible pool recovery sends from the outset, including 401/429 sends before the first billing refusal; exhaustion keeps the terminal upstream body, including an image-tier 413 reached after billing recovery. Refusal bodies retained for replacement are drained through the existing 64 KiB / five-second bounded error reader, then rebuilt without a pacing lease before waiting for replacement capacity; unread, oversized or stalled bodies cannot keep that slot. Cancellation sends no replacement. Ordinary 400s, same-key retry settings and OAuth account routing retain their contracts. `tests/responses/responses-anthropic-billing-send-budget.test.ts` isolates actual dispatch and the non-enforced budget owner to pin mixed refusal ceilings and terminal image formatting. `tests/server/server-anthropic-billing.test.ts` exercises both lanes, concurrency leases, overrides, exhaustion, mixed refusal classes, cancellation and text/tool commit boundaries.
