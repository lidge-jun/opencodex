These are **static snapshots** of public leaderboards, refreshed manually — not live OpenCodex metering. Each board lists its source, capture date, and license note. A score-per-dollar column and best-value badge appear only when every row has a source-measured cost per task. Rows keep the dataset's order; they are not ranked by score per dollar.

Boards are grouped by task domain:

- [Coding](./coding/) — DeepSWE, AA Coding Agent, FrontierCode, FrontierSWE, Program Bench, SWE Marathon
- [Frontend](./frontend/) — Frontend Code Arena
- [Terminal](./terminal/) — Terminal Bench 2.1
- [Security](./security/) — Cybench
- [Intelligence](./intelligence/) — AA Intelligence Index
