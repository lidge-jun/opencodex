Bu sayfalar, genel lider tablolarının **statik anlık görüntüleridir** ve elle
güncellenir — canlı OpenCodex ölçümü değildir. Her pano kaynağını, kayıt
tarihini ve lisans notunu belirtir. Puan/dolar sıralaması yalnızca her satırın
kaynak tarafından ölçülmüş görev başı maliyet içerdiği panolarda görünür.

Panolar görev alanlarına göre gruplandırılmıştır:

- [Kodlama (Coding)](./coding/) — DeepSWE, AA Coding Agent, FrontierCode,
  FrontierSWE, Program Bench, SWE Marathon
- [Ön Yüz (Frontend)](./frontend/) — Frontend Code Arena
- [Terminal](./terminal/) — Terminal Bench 2.1
- [Güvenlik (Security)](./security/) — Cybench
- [Zeka (Intelligence)](./intelligence/) — AA Intelligence Index
