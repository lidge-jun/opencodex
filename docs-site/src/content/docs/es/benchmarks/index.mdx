Estas tablas son **instantáneas estáticas de clasificaciones públicas, actualizadas manualmente**. No son mediciones en vivo de OpenCodex. Cada panel indica la fuente, la fecha de captura y la licencia. Las clasificaciones de puntuación por dólar solo se muestran cuando la fuente aporta un costo medido por tarea para **todas las filas** del panel.

Los paneles se agrupan por tarea:

- [Programación](./coding/) — DeepSWE, AA Coding Agent, FrontierCode, FrontierSWE, Program Bench, SWE Marathon
- [Frontend](./frontend/) — Frontend Code Arena
- [Terminal](./terminal/) — Terminal Bench 2.1
- [Seguridad](./security/) — Cybench
- [Inteligencia](./intelligence/) — AA Intelligence Index
