Estas tablas son **instantáneas estáticas de clasificaciones públicas, actualizadas manualmente**. No son mediciones en vivo de OpenCodex. Cada panel indica la fuente, la fecha de captura y la licencia. La columna de puntuación por dólar y la insignia de mejor relación entre puntuación y coste aparecen solo cuando todas las filas tienen un coste medido por tarea. Las filas conservan el orden de los datos; no se clasifican por puntuación por dólar.

Los paneles se agrupan por tarea:

- [Programación](./coding/) — DeepSWE, AA Coding Agent, FrontierCode, FrontierSWE, Program Bench, SWE Marathon
- [Frontend](./frontend/) — Frontend Code Arena
- [Terminal](./terminal/) — Terminal Bench 2.1
- [Seguridad](./security/) — Cybench
- [Inteligencia](./intelligence/) — AA Intelligence Index
